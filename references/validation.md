# 交付验证清单

## 文件验证

- `SKILL.md` frontmatter 的 `name` 与目录名一致，description 非空且包含触发场景；
- JSON 可解析，Skill ID 唯一；
- HTML 内嵌 JSON 与外部 JSON 的 Skill 数量和 ID 一致；
- 每条记录至少有名称、用途、环境、来源路径、主 Prompt 和变体；
- 没有残留 `{{ATLAS_...}}` 模板 token；
- 脚本通过 `python3 -m py_compile`。

## 浏览器验证

1. 直接双击 HTML，确认无需服务器即可打开；
2. 搜索完整 Skill 名称，确认精确结果优先；
3. 搜索中文任务词，确认显示命中原因；
4. 点击任务入口，确认搜索被清空且结果发生变化；
5. 点击环境、主题、收藏、多端共有；
6. 打开详情，确认来源、原始说明、主 Prompt 和 4 个变体；
7. 套用一个变体，确认编辑器改变但尚未自动保存；
8. 编辑、保存、重置 Prompt，刷新页面确认本地保存；
9. 复制 Prompt，检查复制提示；
10. 生成安装/删除命令，确认不执行命令，删除命令指向系统废纸篓；
11. 测试 375px 和桌面宽度，确认弹窗、搜索和卡片不溢出；
12. 检查控制台没有错误。

任何一项失败，都把页面、操作、预期、实际和复现步骤写入 README 的“已知问题”，不要宣称全部通过。
